Print and web disagree on the teal. The FY2024–25 report declares #00B2B9; snowyhydro.com.au publishes #00AEB6 in its msapplication-TileColor. Both are real, neither is wrong — this sheet uses the print value because it is corroborated across 377 fill operators. Confirm which the client considers canonical before shipping.

The ramp shifts hue as it lightens, and that's faithful. Snowy's system runs near-black navy on covers, deep slate on section pages, teal for accents, then pale teal tints. It reads as one dark-to-light ladder in the report, so it is tokenised as one.

Amber is 1.93:1 on white — it only works against the navy and slate surfaces, where it is excellent. Treat it as a dark-mode accent, not a light-mode one. It is also chart series 3, so keep the meaning consistent.

Watch the amber/warning overlap. Brand amber #FAAB1A and semantic warning #8A5300 are the same hue at different luminance. Amber is brand and appears on dark surfaces; warning is semantic and appears on light. Never put them in the same view.

Chart series — fixed order

A genuine categorical palette — the first in the client set. Snowy's report carries five distinct chart hues, all extracted as fill operators and all confirmed to render. Unlike CleanCo, EnergyAustralia or CS Energy, this separates on hue rather than luminance alone, so it will carry five unrelated categories. Dash patterns still recommended.
