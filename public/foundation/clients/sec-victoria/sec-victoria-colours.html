Transpose checklist — new client brand

Fill these roles for a new client. Spacing, type scale, radii and icons stay on the Tally density system — only colour, logos and font change.

  • primary — deepest brand (headings, CTA, selection)
  • primaryStrong — app bar (lighter than primary)
  • primaryMuted — secondary text / links
  • primaryTint — card / active nav wash (~50)
  • primaryWash — page gradient start (~25)
  • accent — marks & rings (not text on white)
  • accentOnPrimary — accent readable on brand surface
  • accentTint — soft callout background
  • text / textMuted / border / surface — neutrals
  • danger / success / warning — semantic
  • 5 chart series + dash patterns — fixed order
  • Nav active colours — bg, text, dark variants
  • Logos — standard + reversed (+ sizes)
  • Font — or keep Inter until licensed
