Brand anchors

Ampol blue
#18249C · blue-700
Ampol red
#ED0C06 · red-600

Red is both the brand accent and the universal signal for error / negative. This collision is the single biggest risk in this palette. Reserve #ED0C06 for brand chrome only (logo, active nav, one hero accent). Semantic danger is the darker #B90905 in the semantic set below — not part of the red scale — so the two stay separable, and always pair a negative value with a sign or arrow, never colour alone.

The two anchors must never touch. Red on Ampol blue is 2.63:1 — it fails even the 3:1 non-text threshold. For accent on a blue surface use red-300 #F7928F (5.34:1).

Chart series — fixed order

Charts stay on the blue scale. Brand red is reserved for UI chrome (icons, tabs, focus rings) and never used as a series colour, so data marks never read as error / negative. Semantic danger remains #B90905. Series 1–4 are a single hue, so dash patterns are load-bearing — pair every series with one.
